# 摄影作品集 · 维护说明

静态站点，由构建脚本从原图生成。**所有内容都是脚本产物，不要手改** `index.html` 或
`grid/`、`photos/` 里的文件 —— 下次重建会被覆盖。

## 页面结构

**版面式**编排：一版 2~4 张照片，版与版之间留出大片空白。

- **封面**：标题 + 统计（地区 / 版面 / 作品）
- **24 个版面**：按**地点**归类；版内照片大小交错（每张宽度不同 + 左右错位）
- **两层注释**：
  - 版头一条**整版说明**（中英双语）
  - 每张图下方一条**简短介绍**（中英双语 + 序号）
- 顶栏地区导航（滚动自动高亮）、灯箱（键盘 / 触屏滑动）、回到顶部

## 地区与地点划分

`_build/scan-by-region.mjs` 顶部两张表决定归类：

1. **`REGIONS`** —— 哪个地点关键词属于哪个地区
2. **`PLACE_MERGE`** —— 哪些地点名在页面里合并显示为同一个

当前结果（10 个地区）：

| 地区 | 地点（已合并） | 张数 | 版面 |
|---|---|---|---|
| 新疆 | 新疆（含喀纳斯、赛里木湖） | 18 | 5 版 |
| 川西 | 川西、九寨沟、稻城亚丁、四姑娘山 | 24 | 7 版 |
| 辽宁 | 大连 | 11 | 3 版 |
| 山东 | 青岛 | 7 | 2 版 |
| 江苏 | 连云港（含花果山、连岛） | 5 | 2 版 |
| 甘肃 | 七彩丹霞、扎尕那、中卫 | 4 | 1 版 |
| 黑龙江 | 哈尔滨 | 3 | 1 版 |
| 青海 | 青海（含青海湖） | 3 | 1 版 |
| 浙江 | 杭州 | 2 | 1 版 |
| 湖北 | 武汉 | 1 | 1 版 |

> `PLACE_MERGE` 的合并规则都是按你的要求做的：
> 喀纳斯/赛里木湖 → 新疆；花果山/连岛 → 连云港；圣索菲亚教堂 → 哈尔滨；青海湖 → 青海。
> 不合并的话，同一趟旅程会被拆成多个地点、出现"喀纳斯+新疆"这类混版标签。

## 版面是怎么分的

`_build/plan-plates.mjs`，规则：

1. 地点照片数 **> 4 张** → 在该地点内部**均分**
   （新疆 18 → `4,4,4,3,3`；大连 11 → `4,4,3`；川西/九寨沟 8 → `4,4`）
   —— 这保证"同一地点内部各版张数一致"
2. 其余小地点按顺序合并，累计到 **3 张**就收版；放不下（会超 4 张）则提前收版
3. 张数不足 2 的版面只可能来自"单张地点"（如武汉 1 张），当整幅大图处理

**注意**：你要的是「每个版面**内部**分布均匀」，而不是「所有版面张数一致」——
所以版面之间张数可以是 2/3/4 不同，这是刻意的。

可调常量：`MIN=2`、`TARGET=3`、`MAX=4`。

当前分布 `4,4,4,3,3,4,4,3,2,4,4,3,4,4,4,3,3,2,4,3,3,3,1,2`（平均 3.25，标准差 0.83）。

## 加照片的流程

**1. 把新照片放进原图文件夹**

```
C:\Users\Sprind\Desktop\网页
```

文件名写成「地点 (序号).jpg」，例如 `青岛 (8).jpg`。
**地区归类完全靠文件名**（子串匹配 `REGIONS`），新地点要先加进表里。

**2. 双击重建脚本**

```
C:\Users\Sprind\Documents\deepseek-harness\default-workspace\rebuild-portfolio.cmd
```

依次执行：扫描归类 → 缩放两档图片 → 规划版面 → 生成网页。

**3. 给新照片补介绍**

新照片没有介绍时，图下会留空。要生成的话单独跑：

```
C:\Users\Sprind\Downloads\SnowLuma-v1.14.20-win-x64\node.exe ^
  "C:\Users\Sprind\Documents\deepseek-harness\default-workspace\annotate-captions.mjs"
```

它用视觉模型逐张看图写中英介绍，**自动跳过已有条目**，每张约 2~3 秒。

**4. GitHub Desktop 提交并推送**

Commit to main → Push origin。等 1~2 分钟网站自动更新。

## ⚠️ 关于文件编号

页面里的图片文件名带顺序号（`001_`、`002_`…），按文件名排序现场生成。所以：

- ✅ 新照片名字**排在已有照片之后** → 已有编号不变，只推送新增的几张
- ❌ 新照片名字排在中间，或**删除 / 改名**中间的图 → 后面全部重新编号，
  Git 会认为所有图片都变了，要重传约 **97 MB**

## 交互效果

- 滚动时照片有轻微**视差**（图片在框内缓慢位移）
- 照片滚入视口时**淡入 + 上浮 + 去模糊**，同版内错开 90ms
- 悬停：阴影加深 + 图片缓慢放大
- 顶栏地区导航滚动自动高亮，点击跳到该地区第一个版面
- 右下**回到顶部**
- 灯箱：点击放大、`← →` 切换、`Esc` 关闭、**触屏左右滑动切换 / 下滑关闭**、相邻预取
- 跟随系统**深色模式**；系统开启「减少动效」时全部动画关闭
- 窄屏自动改为单列

## 环境依赖

- **Node**：本机随 QQ Agent 自带一份，脚本里写死了路径
- **图片缩放**：Windows 自带的 System.Drawing，无需额外安装
- **生成照片介绍**：需要 `~/.dsh/.credentials.yaml` 里的 `DEEPSEEK_API_KEY`
